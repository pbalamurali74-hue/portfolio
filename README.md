## 🛠️ Tech Stack & Architecture

- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons, GSAP Animation, Three.js / Canvas 3D HUD
- **Deployment:** Vercel (CI/CD via GitHub integration)
- **State & Data:** Modular data schema in `src/data/portfolioData.js`

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/pbalamurali74-hue/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
