## 🌟 Featured Projects

### 1. 🛰️ [GEOSHIELD: Flood Exposure & Emergency Decision Intelligence](https://github.com/pbalamurali74-hue/geoshield-flood-intelligence)
- **Overview:** Radar physics flood detection pipeline utilizing Copernicus Sentinel-1A C-band SAR to penetrate 100% cyclone cloud cover. Maps water surfaces via specular microwave backscatter drop (-5.68 dB) and evaluates 506 1-km² sectors with zero double-counting mathematical bijection.
- **Technologies:** Sentinel-1 SAR, GeoPandas, Rasterio, Copernicus DEM, ESA WorldCover, MapLibre GL, React, Vite
- **Impact & Scale:** 487.92 km² extent, 272 exposed buildings, 17.78 km submerged roads, 0.00% reconciliation discrepancy.
- **Live Demo:** [geoshield-flood.vercel.app](https://geoshield-flood.vercel.app)

### 2. ✈️ [NASA Turbofan Engine RUL Prediction (PyTorch LSTM)](https://github.com/pbalamurali74-hue/Turbofan-Engine-RUL-Prediction)
- **Overview:** End-to-end predictive maintenance system estimating Remaining Useful Life (RUL) of turbofan machinery using NASA C-MAPSS multivariate sensor telemetry. Prevents data leakage with engine-level splits and benchmarks Linear Regression, Random Forest, XGBoost, and PyTorch LSTM.
- **Technologies:** Python, PyTorch, LSTM, XGBoost, Scikit-Learn, Streamlit, Pandas, NumPy
- **Key Result:** PyTorch LSTM achieved **14.72 RMSE, 11.19 MAE, and 0.8745 R²** with an interactive Streamlit maintenance console.
